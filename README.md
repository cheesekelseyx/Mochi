# Terminal Companion
A tiny cat living quietly in your terminal.
The companion does not try to solve problems or demand attention. It shares a quiet terminal world with the player through simple interactions, ASCII animation, music, changing weather, and small moments. 
The project is currently in its early design stage.

## Design philosophy
* Everyone is gentle.
* The world is cozy, not busy.
* Nothing exists only to increase engagement.
* The companion has its own personality and agency.
* The player may leave and return without punishment.

## Planned first version
* ASCII cat;
* pet interaction;
* feed interaction;
* sit together;
* simple dialogue;
* cross-platform Python terminal support.

See the `docs/` directory for the complete vision and roadmap.
