# Design
## Visual design
Mochi uses a small fixed-width ASCII design.
## Base appearance
​```text
 /\_/\
( o.o )
 > ^ <
 /   \
 \_v_/
​```
Ps: The third line represents Mochi's neck and chest fur, not its hands.

## Animation
Version 0.1 includes:
- blinking;
- gentle tail movement;
- a short response to petting.
Animations are created by displaying ASCII frames at different intervals.

## Interaction
The player interacts with Mochi through simple terminal commands.
Version 0.1 does not include:
- hunger or thirst requirements;
- punishment for leaving;
- complex personality development;
- music;
- AI-generated conversation.
