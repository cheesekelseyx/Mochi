# MochiScript Style Guide
## Base cat

```text
 /\_/\
( o.o )
 > ^ <
 /   \
 \_v_/
```
Do not alter the base cat without an intentional design decision.

## Visual layers
1. ASCII for the main cat and selected recurring characters.
2. Unicode and emoji for environmental details.
3. Box-drawing characters for terminal interface elements.

## Visual principles
* use simple silhouettes;
* leave empty space;
* avoid dense character art;
* use eyes and posture to communicate expression;
* allow different objects to use different sizes;
* do not force every object into ASCII;
* suggest more rather than drawing more.

## Approved recurring ASCII characters
* cat;
* bird;
* mouse;
* rabbit;
* fox;
* hedghog
* box-cat;
* bread-cat;

## Prefer Unicode or emoji for difficult shapes
* 🦋 butterfly;
* 🐸 frog;
* 🐢 turtle;
* 🌙 moon;
* 🍵 tea;
* seasonal and weather symbols.
